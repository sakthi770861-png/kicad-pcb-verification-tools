# Codex for Open Source: evidence checklist

This repository can be submitted as supporting evidence **if its owner actually maintains it**. It does not itself grant or guarantee ChatGPT Pro or API credits.

The OpenAI Codex for Open Source program evaluates actual maintainers of meaningful open-source software. The appropriate approach is to publish working source code, document releases, respond to legitimate issues, and build real third-party usage over time. There is no guaranteed qualification based solely on a new repository.

Suggested application evidence (only when accurate):

- Public repository with identifiable versioned source code and open-source license.
- Maintainer contribution history and issue/PR response record.
- Working automated tests and reproducible demonstrations.
- Real adoption or downloads, with numbers verified directly from GitHub or package registries.
- Concrete explanation of how Codex will be used for open-source maintenance (e.g. tests, parser updates, reviewing PRs and documentation).

Never invent GitHub stars, downloads, user numbers, maintainership history, or claims that hardware safety was validated. Keep private client files and unpublished personal work out of an application unless permission is explicit.
